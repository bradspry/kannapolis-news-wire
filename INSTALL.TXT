KCAT INSTALLATION GUIDE
=======================
Local news & events monitor for Kannapolis, NC
Requires Python 3.9 or later (python.org)


QUICK START (ALL PLATFORMS)
----------------------------
1. Unzip the backup file into a folder of your choice.
2. Open a terminal / command prompt and navigate to the unzipped folder:

   cd kspider

3. Install the package and all dependencies:

   pip install -e .

4. Add kspider to your PATH (see platform section below), then verify:

   kspider --help

5. Run your first search:

   kspider search

6. Export and open the dashboard:

   kspider export --open


─────────────────────────────────────────────────────────────────────────────
macOS
─────────────────────────────────────────────────────────────────────────────

PREREQUISITES
  • Python 3.9+  →  brew install python3   (or download from python.org)
  • Homebrew     →  https://brew.sh  (recommended)
  • lxml system libs (usually already present; install if pip install fails):
      brew install libxml2 libxslt

INSTALL STEPS
  unzip kcat_backup_YYYYMMDD_HHMMSS.zip
  cd kspider
  pip3 install -e .

ADD TO PATH (run once — replace 3.x with your Python version e.g. 3.9, 3.12)
  echo 'export PATH="$HOME/Library/Python/3.x/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

Find your Python version with: python3 --version

RUN (LOOP MODE WITH AUTO-EXPORT)
  kspider search --loop --interval 30 --export kspider/kspider/kcat.html


─────────────────────────────────────────────────────────────────────────────
WINDOWS
─────────────────────────────────────────────────────────────────────────────

PREREQUISITES
  • Python 3.9+  →  download from python.org
    During install, CHECK the box "Add Python to PATH"
  • curl is included with Windows 10/11. Verify with:
      curl --version
    If missing, download from https://curl.se/windows/

INSTALL STEPS (Command Prompt or PowerShell)
  Expand-Archive kcat_backup_YYYYMMDD_HHMMSS.zip -DestinationPath .
  cd kspider
  pip install -e .
  kspider --help

If "kspider" is not found, add Python's Scripts folder to your PATH:
  python -m site --user-site
  (replace \site-packages with \Scripts in that path, add to System PATH)

RUN (LOOP MODE WITH AUTO-EXPORT)
  kspider search --loop --interval 30 --export kspider\kspider\kcat.html

NOTE: The countdown "press Enter to run now" feature requires Windows
      Terminal or PowerShell. It may not work in older cmd.exe windows.


─────────────────────────────────────────────────────────────────────────────
LINUX
─────────────────────────────────────────────────────────────────────────────

PREREQUISITES
  • Python 3.9+  →  usually pre-installed; check with: python3 --version
  • pip:
      sudo apt install python3-pip        # Debian/Ubuntu
      sudo dnf install python3-pip        # Fedora/RHEL
  • lxml build dependencies:
      sudo apt install libxml2-dev libxslt-dev python3-dev  # Debian/Ubuntu
      sudo dnf install libxml2-devel libxslt-devel          # Fedora/RHEL
  • curl:
      sudo apt install curl
      sudo dnf install curl

INSTALL STEPS
  unzip kcat_backup_YYYYMMDD_HHMMSS.zip
  cd kspider
  pip3 install -e .

ADD TO PATH (run once)
  echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc

RUN (LOOP MODE WITH AUTO-EXPORT)
  kspider search --loop --interval 30 --export kspider/kspider/kcat.html


─────────────────────────────────────────────────────────────────────────────
COMMON COMMANDS
─────────────────────────────────────────────────────────────────────────────

  kspider search                        Run a single search across all sources
  kspider search --loop                 Run repeatedly (default: every 30 min)
  kspider search --loop --interval 15   Run every 15 minutes
  kspider search --source CivicClerk    Run a single source only
  kspider export                        Export dashboard to kcat.html
  kspider export --open                 Export and open in browser
  kspider results                       Browse stored results in terminal
  kspider runs                          List past search runs

LOOP MODE TIPS
  • The terminal shows a live countdown to the next run.
  • Press Enter at any time to trigger an immediate run without waiting.
  • Press Ctrl-C to stop the loop.

─────────────────────────────────────────────────────────────────────────────
DASHBOARD FEATURES
─────────────────────────────────────────────────────────────────────────────

  • Chip and list view modes
  • Filter by source or query using the left sidebar
  • Text search box — searches all stories including dismissed ones
  • Click ✕ on a chip to dismiss/block it permanently
  • "Show blocked (N)" button reveals dismissed stories with an Unblock button
  • Facebook Share button (hover over chip, bottom-right) — copies the URL
    to clipboard and opens the KTalk Facebook group in a new window
  • Paste the URL directly into the KTalk group composer to share


─────────────────────────────────────────────────────────────────────────────
DATA & FILES
─────────────────────────────────────────────────────────────────────────────

  Database:    ~/.kspider/results.db        (created automatically on first run)
  Dashboard:   kspider/kspider/kcat.html    (regenerated by kspider export)
  Favicon:     kspider/kspider/favicon.png  (copied alongside kcat.html)

  Dismissed/blocked story history is stored in the browser's localStorage.
  It is browser-specific and will not transfer between computers or browsers.


─────────────────────────────────────────────────────────────────────────────
BACKUP
─────────────────────────────────────────────────────────────────────────────

  To create a new backup zip at any time, run from the dev folder:

  zip -r kcat_backup_$(date +%Y%m%d_%H%M%S).zip kspider/ \
    --exclude "kspider/.git/*" \
    --exclude "kspider/__pycache__/*" \
    --exclude "kspider/kspider/__pycache__/*" \
    --exclude "kspider/kspider/sources/__pycache__/*"


─────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

  "command not found: kspider"
    → Add Python's bin/Scripts dir to your PATH (see platform section above)
    → Or run directly: python3 -m kspider --help

  "No module named kspider"
    → Run: pip install -e .  from inside the kspider folder

  "lxml not found" or build error during pip install
    → Install system libs first (see platform section above)

  Dashboard shows "No data"
    → Run: kspider search   then: kspider export --open

  Sources returning errors
    → Some sources (Bing, DuckDuckGo) may rate-limit occasionally.
      Errors are skipped and the run continues normally.
      Results will improve on the next run.

  Duplicate stories appearing
    → Run: kspider export --open  to regenerate — deduplication is automatic.
